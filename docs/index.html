About Me

Hi! I'm Nazmi Yücel Çan. I am an Information Systems and Technologies graduate and a Machine Learning Engineer / Data Scientist focused on deploying and optimizing AI models in production environments. I co-authored an academic paper with my team members, published in the El-Cezeri Journal of Science and Engineering (2026), on deep learning models integrating attention mechanisms (Attention U-Net/U-Net++) for military camouflaged object detection. During my internship at Deep Think Technology, I developed industrial computer vision systems featuring real-time YOLOv8-seg inference, PyQt5 GUI design, and camera SDK integration. I am experienced in optimizing Small Language Models (SLMs like mT5) and Edge AI/TinyML applications (SVM on Arduino) using ONNX Runtime and INT8 quantization for resource-constrained devices. I developed Zettelkasten AI Notes, a privacy-first desktop knowledge management system featuring a Two-Tier Vector RAG pool, CPU cross-encoder reranking, and Vulkan-accelerated local GGUF models alongside Google Gemini, ranking in the top 10 finalists of the Pupilica AI Hackathon. My primary focus lies in end-to-end model development workflows—from data preprocessing and model training to deployment and optimization in computer vision and natural language processing.

mT5 Bidirectional EN-TR Machine Translation (ONNX INT8 & ORT Mobile)

Fine-tuned an mT5-small model with 8-bit LoRA for bidirectional English-Turkish translation, achieving a 0.6245 METEOR score. Reduced model size 5x (from 500MB to 100MB) and optimized performance for resource-constrained environments by applying model pruning, ONNX compilation, and INT8 quantization for mobile deployment via ONNX Runtime (ORT Mobile).

Python PyTorch Transformers LoRA

Zettelkasten AI Notes (Pupilica AI Hackathon — Top 10 Finalist)

A privacy-first desktop knowledge management application implementing the Zettelkasten method using Python and Flet. Features a Dual AI Engine (Google Gemini and Vulkan-accelerated local GGUF models) with a Two-Tier In-Memory Vector RAG Pool, CPU cross-encoder reranking (Qwen3), and local embeddings (Harrier-0.6B) to synthesize atomic notes without duplicate concepts. Includes an interactive canvas mind map, live Markdown editor with LaTeX, smart WikiLinks, and SQLite WAL persistence.

Python Flet SQLite RAG

Apple Detection and Quality Analysis System

An industrial computer vision application featuring real-time object detection, physical dimension measurement, and CIEDE2000 color quality analysis. Focused on system integration, designing the application architecture, and orchestrating the end-to-end pipeline—integrating the camera SDK, real-time YOLOv8-seg model inference, and measurement modules into a unified desktop interface.

Python OpenCV YOLO PyQt5

Arduino PC System Monitor

A TinyML-powered system that monitors PC hardware resources (CPU, RAM, GPU, VRAM) and automatically optimizes power consumption. The system extracts hardware telemetry in real-time, executing an on-device SVM classification model on an Arduino Leonardo to determine and adjust the system's power state.

Python Arduino TinyML scikit-learn
